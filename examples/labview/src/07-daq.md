# 第七章 数据采集

> 分值最高的一章。四个必考点：采集卡指标（分辨率公式）、三种接入方式、DAQmx 编程流程、采样数与采样率的关系。

## 7.1 系统构成

```
被测对象 → 传感器 → 信号调理 → 数据采集（A/D）→ 计算机处理 → 显示
                                              ↓
                        执行机构 ← 功率放大 ← D/A
```

- **传感器**：把非电量（温度、压力、位移）转成电量。
- **信号调理**：放大或衰减到量程、隔离被测系统与采集系统、滤波（含**抗混叠滤波器**）。
- **数据采集**：采样、保持、量化、编码四步，核心是 A/D。

采样要不失真，需要两个条件：采样频率足够高、被采样信号是**带限信号**。工程上用低通滤波器在 A/D 之前把信号变成带限信号，这个滤波器就叫抗混叠滤波器。

## 7.2 采集卡的关键指标

::: def 分辨率
采集卡能分辨的最小电压变化量，由 A/D 的位数决定：

$$\text{分辨率}=\frac{\text{输入电压范围}}{2^{n}}$$

例如 12 位卡、0～10 V 量程，分辨率为 $10/2^{12}\approx 2.44\ \text{mV}$。
:::

| 指标 | 含义 | 考点 |
|---|---|---|
| 采样精度 | 受分辨率、零位误差、零漂影响 | 分辨率不等于精度 |
| 采样频率 | 每秒采样点数 | 频域还原需 ≥2 倍最高频率；时域看清波形需 5～10 倍 |
| 通道数 | 可采样的路数 | 多通道复用时分给每路的速率 = 最高速率 ÷ 通道数 |
| 同步与触发 | 多通道是否同时采样 | 公用 A/D 为扫描式（分时），独占 A/D 为同时采样 |
| 总线与隔离 | PCI/USB/PXI，是否隔离 | 影响抗干扰与安装方式 |

## 7.3 三种接入方式

被测信号分**接地信号源**（如信号发生器、电源）与**浮地信号源**（如电池、热电偶、隔离放大器）。

| 方式 | 接法 | 优点 | 缺点 |
|---|---|---|---|
| 参考单端 RSE | 每路正端接 AI，负端接 AIGND | 通道利用率高 | 不能抑制共模电压 |
| 非参考单端 NRSE | 负端统一接 AISENSE | 比 RSE 共模抑制好 | 仍非全差分 |
| 差分 DIFF | 正负端分别接 AI+、AI− | 抑制共模干扰最好 | 占用双倍通道 |

选择原则：**接地信号源优先差分或 NRSE，浮地信号源可用差分或 RSE**；干扰大、导线长时一律差分。

## 7.4 软件：从 MAX 到 DAQmx

1. 安装采集卡与驱动 **NI-DAQmx**；
2. 在 **MAX** 中识别设备、做测试面板自检；
3. 在 LabVIEW 中编程，两条路线：

| 路线 | 特点 | 适用 |
|---|---|---|
| DAQ 助手（Express VI） | 对话框配置，快速出结果 | 快速验证、教学 |
| DAQmx 函数 | 参数显式，灵活、可复用 | 正式程序 |

DAQmx 程序固定五步：

```
创建任务 → 配置（通道/量程/接线/定时）→ 开始任务 → 读取 → 清除任务
```

三个术语必须分清：

- **任务**：一次数据采集过程的容器；
- **虚拟通道**：带名称、物理通道、接线方式、信号类型、单位等属性的测量通道；
- **物理通道**：采集卡上的接线端子，如 `Dev1/ai0`。

**采样模式**有三种：1 采样（按要求）、N 采样（有限）、连续采样。采样数与时间的关系：

$$N_{\text{采样}}=f_s\times t$$

::: example 例 7-1 | 采样参数计算
采样率 $f_s=1000\ \text{Hz}$，采集 5 s，每通道需要多少采样点？若改为 8 通道复用同一块卡，每通道最高采样率是多少？
---
采样点数 $N=1000\times5=5000$ 点/通道。
多通道复用同一个 A/D 时，总采样率被各通道分时占用，每通道速率 = 卡的最高采样率 ÷ 通道数。若该卡最高 100 kS/s，8 通道时每通道 12.5 kS/s。
注意：若卡是每通道独立 A/D（同时采样），则不受此限制。
:::

## 7.5 用声卡做数据采集

声卡本身就是一套低成本的 A/D + D/A 系统，适合音频域（20 Hz～20 kHz）信号。

| 接口 | 幅值范围 | 说明 |
|---|---|---|
| Line In | < 1.5 V | 线路输入，最常用 |
| Mic In | 0.02～0.2 V | 内置高增益放大，接麦克风 |
| Line Out | 未经放大 | 接功放或有源音箱 |
| SPK Out | 经功放 | 直接驱动扬声器 |

声卡的采样率固定为 44.1 kHz 等几档，不能连续调节；**不提供基准电压**，所以测得的数字量必须标定后才能换算成实际电压。

编程五步：配置声音输入（设备 ID、声音格式、采样模式、每通道采样数）→ 启动 → 读/写 → 停止 → 清除。

::: quiz 自测
12 位采集卡、量程 −5～+5 V，分辨率是多少？为什么说分辨率高不等于精度高？
答案：分辨率 $=10/2^{12}\approx2.44\ \text{mV}$。精度还受零位误差、温漂、非线性、噪声与校准影响；分辨率只说明“能分辨的最小台阶”，台阶小不代表台阶位置准确。
:::
