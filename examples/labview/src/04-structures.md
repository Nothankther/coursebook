## 4.1 For 循环与 While 循环

| 项目 | For 循环 | While 循环 |
|---|---|---|
| 循环次数 | 由 N 端子指定 | 由条件端子决定，次数不定 |
| 计次端子 i | 0, 1, …, N−1 | 0, 1, … |
| 条件端子 | 无 | 真时停止 / 真时继续 |
| 隧道自动索引 | 默认打开 | 默认关闭 |
| 等价 C 语句 | `for(i=0;i<N;i++)` | `do{…}while(cond)` |

两个细节常考：

1. **循环次数取最小**：For 循环接多个数组且都开启索引，同时 N 也接了常量时，实际循环次数取三者中的最小值；N 未接线时取最短数组的长度。
2. **While 至少执行一次**：先执行后判断，所以停止按钮接条件端子时，循环体一定会跑一遍。

::: warn 死循环
While 循环的条件端子若恒为“真时继续”，且循环体内没有延时或停止条件，程序会占满 CPU、界面卡死。加“等待(ms)”函数或把停止按钮接进条件。
:::

## 4.2 隧道与移位寄存器

数组进出循环要通过**隧道**。隧道有两种状态：空心方框 `[ ]` 表示索引打开，每次送一个元素；实心方块表示索引关闭，整个数组进出一趟。

**移位寄存器**用于在循环的两次迭代之间传递数据：右侧端子写、左侧端子读，第 i 次循环读到的是第 i−1 次的值。

::: example 例 4-1 | 累加 1 到 100
用 For 循环求 1+2+…+100，N=100。
---
循环内：`Sum = Sum + (i+1)`，其中 Sum 来自左侧移位寄存器，结果接右端。
左侧移位寄存器**必须初始化**为 0（在循环外接常量 0）。
若未初始化，第一次运行得到 5050；第二次运行会带着上次的 5050 继续累加，得到 10100——这是考试常设的陷阱。
:::

移位寄存器可以添加多个元素（右键左侧端子 → 添加元素），保存 i−1、i−2 等历史值；反馈节点则是它的简化形式。

## 4.3 条件结构

条件结构根据**选择器**的值执行某个分支。选择器可以是布尔、字符串、整型、枚举或错误簇。

- 布尔：两个分支（真/假）；
- 整型/枚举/字符串：可有多个分支，标签支持范围 `1..5` 与列表 `1,3,5`；
- **必须有默认分支**，否则未列出的值无法处理，程序报错；
- 输出隧道要求**每个分支都连线**，只要有一个分支没接，隧道就是断的。

## 4.4 顺序结构与事件结构

**顺序结构**强制按顺序执行，分平铺式与层叠式，二者可互相转换。推荐平铺式：连线清楚。它能解决“必须先算 A 再算 B”的问题，但会掩盖数据流，能不用就不用。

**事件结构**只在事件发生时执行对应分支，避免 While 循环里反复轮询、空耗 CPU。

| 类型 | 发生时机 | 用途 |
|---|---|---|
| 通知事件 | 界面操作完成之后 | 响应按钮、值改变 |
| 过滤事件（带问号） | 界面操作之前，可决定是否放行 | 输入校验，如密码只允许 6 位数字 |

事件源分四级：应用程序、本 VI、窗格、控件。事件结构要设**超时**，否则没有事件时一直等待；用停止按钮结束程序时，必须单独加一个“停止按钮值改变”事件，否则按钮按了也退不出循环。

## 4.5 局部变量、全局变量与属性节点

- **局部变量**：同一个 VI 内对前面板控件的引用，可读可写，必须依附于某个控件。
- **全局变量**：以独立文件存在，可在不同 VI 之间传数据，但**不能用于实时传递**（两次读写不保证同步）。
- **属性节点**：读写对象属性，如控件的可见、闪烁、颜色，图表的历史数据（清空曲线就写空数组）。
- **公式节点**：在框图中用类 C 语法写表达式，适合多变量公式。

::: quiz 自测
用停止按钮控制 While 循环，同时循环内有事件结构，为什么按钮按了程序却不退出？怎么改？
答案：事件结构在没有事件时一直等待，循环体卡在事件结构里，条件端子根本轮不到判断。需要在事件结构中增加“停止按钮：值改变”分支，在该分支里把停止标志置真或直接跳出循环。
:::
