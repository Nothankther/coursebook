## 6.1 图形与图表的区别

| 控件 | 数据来源 | 是否保留历史 | 横坐标 |
|---|---|---|---|
| 波形图（Graph） | 数组、簇、波形 | 否，每次整体刷新 | 可设置（t0、dt） |
| 波形图表（Chart） | 数值、数组、波形 | 是，默认保留 1024 点 | 不可设置 |
| XY 图 | 簇数组（x,y） | 否 | 可不等间隔、可多值 |

一句话记忆：**图是快照，图表是流水账**。

波形图接收数组时，横坐标默认从 0 开始、间隔 1；若用“簇”输入，可同时给出起始 x 与间隔 Δx；用波形数据则自动带 t0 与 dt。

多波形显示有两种做法：长度相同用**二维数组**（一行一条曲线）；长度不同用**簇数组**（每个元素一条曲线）。

图表的三项设置常考：

- **历史长度**：默认 1024 点，超过后旧数据被覆盖；
- **刷新模式**：带状图表（数据左移）、示波器图表（像示波器扫描）、扫描图表；
- **清除历史**：用属性节点把“历史数据”写为空数组。

## 6.2 文件 I/O

LabVIEW 支持四种文件格式：

| 格式 | 特点 | 适用 |
|---|---|---|
| 文本文件 | ASCII，通用可读，占空间大 | 数据交换、表格 |
| 二进制文件 | 紧凑、速度快，需知道数据类型才能读 | 大量数据、中间结果 |
| 数据记录文件 | LabVIEW 特有，按记录存储，读写快 | 结构化记录 |
| TDMS | NI 专用二进制，体积小、速度快 | 实时测量数据 |

任何文件操作都是三步：**打开/创建 → 读/写 → 关闭**。

- **简单函数**：一个函数内含三步，使用简单、灵活性差，例如“写入电子表格文件”“读取电子表格文件”“写入测量文件”。
- **底层函数**：分别调用打开、读、写、关闭，用**文件引用句柄（refnum）**标识文件，并与错误簇串接。效率高，但必须自己保证关闭。

::: warn 三个易错点
① 把“打开文件”放进循环——每轮都打开一次，句柄泄漏，正确做法是在循环外打开、循环内写、循环外关闭。
② 读二进制文件时不指定数据类型——二进制不保存类型信息，读出的字节会被错误解释。
③ 电子表格的“分隔符”与数据中的分隔符冲突——默认是制表符，文本里含制表符就会串列。
:::

::: example 例 6-1 | 保存 100 组随机数
把 100 个随机数及其序号写入 `D:\random.xls`，两列：序号、数值。
---
思路：For 循环 100 次，循环内用“创建数组”把 i 与随机数组成一维数组（两个元素），输出隧道开启索引，得到 100×2 的二维数组。
用“写入电子表格文件”，路径接 `D:\random.xls`，分隔符用制表符，格式串 `%.4f` 控制小数位。
注意：文件路径要在循环外准备好；若要文件与 VI 同目录，用“当前 VI 路径”函数拆分后拼接。
:::

::: quiz 自测
为什么读二进制文件时必须给出数据类型？文本文件为什么不需要？
答案：二进制文件只存字节，不存类型信息，同样的 8 个字节按双精度还是按两个整数解释，结果完全不同，所以读之前必须告诉函数原来写入的是什么类型。文本文件以 ASCII 存储，按行与分隔符解析，类型由转换函数在读取后决定。
:::
