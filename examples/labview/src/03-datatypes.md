## 3.1 数值

LabVIEW 的数值类型分五大类、共 15 种：浮点数（单/双/扩展精度）、定点数、有符号整数、无符号整数、复数。选型看三件事：**范围、精度、内存**。

- 默认数值常量是双精度浮点（DBL）；
- 整数运算不会自动四舍五入，除法要用“商与余数”函数；
- 类型不匹配时 LabVIEW 会自动强制转换，但可能丢精度，程序框图上会出现强制点（红点）。

::: warn 典型错误
把整型常量接到需要双精度的端口，结果被截断；或把 DBL 接到整型显示控件，出现意外的取整。看到程序框图上的强制点就要检查类型。
:::

## 3.2 字符串

字符串是 ASCII 字符集合，用于文本显示、仪器命令发送与下位机通信。**一个英文字符占 1 字节，一个汉字占 2 字节**（课程按 ANSI 计）。

| 函数 | 作用 | 考点 |
|---|---|---|
| 字符串长度 | 返回字符数 | 汉字按字符计，字节数要乘 2 |
| 连接字符串 | 拼接多个字符串或一维数组 | 常用于拼程控命令 |
| 格式化写入字符串 | 按格式把数值等转为字符串 | `%f`、`%.3f` 控制小数位 |
| 截取字符串 | 从偏移量起取指定长度 | 偏移量从 0 开始 |
| 扫描字符串 | 从文本中取出数字并转数值 | 相当于 C 的 `scanf` |
| 匹配正则表达式 | 按模式拆分 | 适合复杂报文 |
| 替换字符串 | 删除/插入子串 | 长度 0 表示插入 |
| 电子表格字符串至数组 | 文本表格转二维数组 | 分隔符要对 |

::: example 例 3-1 | 提取电压值
字符串常量 `Voltage DC=2.356V`，要求取出数值 2.356 并以数值型显示。
---
方法一：用“扫描字符串”函数，格式串写 `Voltage DC=%fV`，输出即为 2.356。
方法二：用“截取字符串”从偏移量 11 开始取 5 个字符，再用“小数数字符串至数值转换”。
方法三：用“匹配正则表达式”，模式写 `[0-9]+\.[0-9]+`，取匹配到的子串再转换。
三种方法都要求偏移量或模式与文本严格对应；文本格式一变就要改参数。
:::

## 3.3 枚举与下拉列表

两者外观相似，底层不同：

| 项目 | 枚举 | 下拉列表 |
|---|---|---|
| 底层数据类型 | 无符号整数 | 字符串 |
| 能否直接参与数值运算 | 能 | 不能 |
| 典型用途 | 条件结构的分支选择 | 界面选项 |

枚举常与条件结构配合：每个枚举值对应一个分支，可读性比用数字好。

## 3.4 布尔与路径

- **布尔**只有真/假两个状态，控件有按钮、开关、指示灯等。按钮的**机械动作**决定按下后何时复位：单击时转换、释放时转换、保持直到被读取等，界面“按一下亮、再按一下灭”就用转换型。
- **路径**是 LabVIEW 特有的数据类型，用于表示文件位置，跨平台时由 LabVIEW 负责分隔符差异。路径常量在“编程 → 文件常量”，路径控件在“控件 → 新式 → 字符串与路径”。

::: quiz 自测
字符串 `"温度25℃"` 的长度函数返回多少？占多少字节？
答案：长度按字符计返回 5（温、度、2、5、℃ 各算一个字符）；按课程约定汉字与全角符号占 2 字节，共 10 字节。实际字节数还取决于编码，答题时以课件约定为准。
:::
