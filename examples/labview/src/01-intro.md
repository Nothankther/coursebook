# 第一章 虚拟仪器概论

## 1.1 定义与两个“虚拟”

::: def 虚拟仪器（VI）
在以通用计算机为核心的硬件平台上，由用户自己设计定义、具有图形化用户界面的软件组成的测控系统，是一种计算机操纵的模块化仪器系统。
:::

“虚拟”体现在两处：

| 虚拟的对象 | 传统仪器 | 虚拟仪器 |
|---|---|---|
| 面板 | 旋钮、开关是实物 | 与实物相像的图标，鼠标键盘操作 |
| 功能 | 由硬件电路决定 | 由软件编程实现 |

由此得到本课程最核心的一句话：**硬件是基础，软件是主体**。硬件只负责物理量与数字量之间的转换，功能的定义、数据的分析与显示全部由软件完成，即“软件就是仪器”。

## 1.2 组成

一个完整的测控系统可以画成一条链：

```
对象 → 传感器 → 信号调理 → A/D → 信号处理/控制算法 → 显示
                                    ↓
             执行机构 ← 功率放大 ← D/A
```

- **硬件**：传感器、信号调理、数据采集卡、总线与机箱。常用形式有 PCI/USB 采集卡、GPIB 仪器加接口卡、PXI/VXI 模块化机箱。
- **软件**：开发平台（LabVIEW）加应用程序。软件层次自下而上为驱动、开发平台、应用。

| 实现方式 | 特点 | 典型场景 |
|---|---|---|
| 基于数据采集卡（PCI/USB） | 最常用，性价比高 | 实验室测量 |
| 基于 GPIB | 传统台式仪器程控 | 示波器、万用表 |
| 基于 PXI/VXI | 模块化、同步性好 | 多通道高速测试 |
| 基于串口/以太网 | 成本低、距离远 | 分布式测控 |

## 1.3 发展与特点

仪器经历了四代：模拟仪器 → 数字化仪器 → 智能仪器 → 虚拟仪器。虚拟仪器自 1986 年 NI 提出后大致分三个阶段：利用计算机增强仪器功能（GPIB、RS-232）→ 开放式仪器结构（插入式采集卡、VXI）→ 虚拟仪器框架被广泛采用。

LabVIEW 的特点可以归成六条：编程简单、开发周期短、高效、开放、可自定义、性价比高。

::: warn 两个常见错误
① 认为虚拟仪器“没有硬件”——错了，硬件负责信号转换，只是功能由软件定义。
② 认为精度由软件决定——错了，精度取决于采集卡的分辨率、量程与信号调理。
:::

::: example 例 1-1 | 概念辨析
“虚拟仪器就是在一台 PC 上装一个软件，不需要任何硬件。”这句话错在哪里？
---
错在“不需要硬件”。虚拟仪器的硬件平台仍然是必需的：传感器把非电量转为电量，信号调理完成放大、隔离、滤波，A/D 把模拟量变为数字量。软件改变的是仪器的**功能定义与人机界面**，不能凭空产生被测信号。准确说法是：硬件负责信号的输入输出，软件负责功能与界面，二者缺一不可。
:::

::: quiz 自测
虚拟仪器的两个“虚拟”分别指什么？由此推出本课程的哪句结论？
答案：虚拟的仪器面板（控件是图标，由鼠标键盘操作）与虚拟的测控功能（由软件编程而非硬件电路实现）。结论是“软件就是仪器”，硬件是基础、软件是主体。
:::
