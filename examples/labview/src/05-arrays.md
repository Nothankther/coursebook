## 5.1 数组

数组是**相同类型**元素的有序集合，索引从 0 到 n−1，每维最多 2³¹−1 个元素。创建分两步：先放一个数组框架（壳），再往壳里放一个元素控件，壳就变成该类型的数组。

| 函数 | 作用 |
|---|---|
| 数组大小 | 返回各维长度 |
| 索引数组 | 取指定索引的元素或子数组 |
| 数组子集 | 从某索引起取一段 |
| 删除数组 / 替换数组 | 删除或替换元素 |
| 初始化数组 | 用同一值填满 |
| 创建数组 | 把多个元素或数组拼成新数组 |
| 重排数组维数 | 改变维度 |
| 一维数组循环移位 | 循环平移 |

**多态化**：同一个加法函数，输入两个数值得到数值，输入数组与数值得到数组，输入两个数组得到逐元素相加的数组。函数会自动适配数据类型，不需要写多个版本。

### 数组与循环

数组进出循环靠隧道，三种典型用法：

1. **索引打开**（默认）：每次循环送入一个元素，循环次数等于数组长度；
2. **索引关闭**：整个数组一次性送入循环；
3. **输出端索引打开**：每次循环产生的结果自动拼成一维数组；若每次产生的是数组，则拼成二维数组，维度顺序与直觉相反（先行后列），必要时用“转置”。

::: warn 常见错误
For 循环同时接入两个长度不同的数组，循环次数取**较短**的那个，长数组多出的元素被丢弃；若要处理全部数据，先补零或用 While 循环加索引。
:::

::: example 例 5-1 | 删除负数
已知一维数组 {2, 0, −1, −2, 3}，去掉小于 0 的元素，输出新数组。
---
用 For 循环加条件结构：数组接入循环（索引打开），循环内判断元素是否 ≥0；条件为真时把元素接到输出隧道（索引打开），为假时不接。
技巧：条件结构的输出隧道在“假”分支也要连线——可以接一个空数组或使用“删除数组”函数配合。
结果应为 {2, 0, 3}。
:::

## 5.2 簇

簇是**不同类型**元素的集合，类似 C 语言的结构体。作用有二：把相关信息打包便于传递；把子 VI 的多个参数合成一个接线端。

- 簇元素的**顺序由放置的先后决定**，不是位置；右键“重新排序簇中控件”可调整。
- **捆绑**合成簇，**解除捆绑**按顺序取出；**按名称捆绑/解除**按标签操作，不怕顺序变化。
- 前面板上的簇，元素必须全是输入控件或全是显示控件，不能混用。

### 错误簇

错误簇是 LabVIEW 的标准错误传递机制，含三个元素：

| 元素 | 含义 |
|---|---|
| status | 真表示有错误，假表示无错误或警告 |
| code | 错误代码，status 为真时非零 |
| source | 错误来源的字符串描述 |

函数通常带“错误输入”和“错误输出”接线端，把它们串起来，错误会沿数据流向后传递；下游函数检测到错误输入为真时，跳过实际运算直接透传，直到被错误处理函数捕获。

## 5.3 波形

波形是一种特殊的簇，含四个部分：

| 成分 | 含义 |
|---|---|
| t0 | 起始时间 |
| dt | 采样间隔（秒） |
| Y | 采样值数组 |
| attributes | 附加属性（名称、单位等） |

“创建波形”函数可把 Y 与 t0、dt 组装成波形；“获取波形成分”则拆开。多通道采集的输出通常是**波形数组**，每个通道一个波形元素。

::: quiz 自测
簇中元素的顺序由什么决定？按名称解除捆绑与普通解除捆绑有什么区别？
答案：由创建簇时放置元素的先后顺序决定，与界面位置无关。普通解除捆绑按顺序输出，顺序变了就取错；按名称解除捆绑按标签取，不受顺序影响。
:::
