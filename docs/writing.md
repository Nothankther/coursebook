# 写作语法

`src/` 下的 `.md` 文件会被渲染成章节，`.html` 文件原样插入。文件按名称排序，因此用 `01-`、`02-` 前缀控制顺序。

## 章节骨架

```markdown
# 第三章 线性系统的时域分析法

> 本章分值最高，三块内容必须练到看见题就知道套哪张表。

<!-- short: ③ 时域分析法 -->
<!-- en: Time-domain analysis -->
<!-- id: c3 -->

## 3.1 典型输入信号
...
```

| 标记 | 作用 |
|---|---|
| `# 一级标题` | 章节标题，进入目录；`NN-` 前缀决定序号 |
| 紧跟标题的 `> 引用` | 章节导语（`ch-desc`），不进入正文 |
| `<!-- short: ③ 时域 -->` | 目录里的短标题，缺省用章节标题 |
| `<!-- en: English -->` | 标题右侧的英文副题 |
| `<!-- id: c3 -->` | 锚点 id，缺省 `c<序号>` |
| `00-` 开头的文件 | 视为封面，不套章节外壳 |

## 文本

```markdown
正文段落，一行写完即可，不要手动折行。

**加粗**、*斜体*、`行内代码`、[链接](https://example.com)
```

## 公式

```markdown
行内：$G(s)=\dfrac{1}{Ts+1}$

独立：

$$
L(\omega)=20\lg|G(\mathrm{j}\omega)|
$$
```

公式由 MathJax 渲染，支持 `\dfrac`、`\begin{bmatrix}` 等常用宏。构建脚本会转义公式里的 `<`、`>`、`&`，所以**不要手写 `&lt;`**——会二次转义并报 `Misplaced &`。

常用宏：`\j` → j，`\dd` → d，`\deg` → °，`\e` → e。

## 列表与表格

```markdown
- 第一条
- 第二条

1. 步骤一
2. 步骤二

| 方法 | 适用 | 代价 |
|---|---|---|
| 时域 | 低阶系统 | 高阶难解 |
```

表格第一行是表头，第二行必须是 `|---|---|` 形式的分隔行。

## 引用与代码

```markdown

```

## 插图

把 SVG 放到 `assets/fig-名称.svg`，正文写：

```html
<!--FIG:名称-->
```

构建时会把 SVG 内容内联进 HTML（不是 `<img>` 引用），所以单文件依然成立。图注直接在下一段写文字即可。

## 折叠例题

```markdown
::: example 例 3-1 | 二阶系统指标计算
已知 $\zeta=0.5$、$\omega_n=2$，求超调量。

先算 $\beta=\arccos\zeta$。
---
$$\sigma\%=\mathrm{e}^{-\pi\zeta/\sqrt{1-\zeta^2}}\times100\%=16.3\%$$
:::
```

`---` 之前是题干，之后是解答。解答默认折叠，打印前自动展开。

## 直接写 HTML

需要精细排版（多栏、自定义组件）时，把内容写成 `.html` 文件，构建时原样插入。也可以用 HTML 片段混在 Markdown 里，只要整行以 `<` 开头。
